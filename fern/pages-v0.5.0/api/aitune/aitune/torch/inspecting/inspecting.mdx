Inspect provided callable object searching for nn.Module members executed as part of forward pass.

Returns:
    InspectedModulesInfo object.

**Parameters:**

<ParamField path="obj" type="Callable | torch.nn.Module">
Callable object to inspect.
</ParamField>

<ParamField path="dataset" type="DatasetLike | DataLoaderFactory | torch.Tensor">
List of tuples with batch size and input.
</ParamField>

<ParamField path="inference_function" type="Callable | None" default="None">
Custom inference function to use for inspection, obj is used by default.
</ParamField>

<ParamField path="number_of_iterations" type="int" default="DEFAULT_INSPECT_ITERATIONS">
Number of iterations to run for inference.
</ParamField>

<ParamField path="warmup_iterations" type="int" default="DEFAULT_WARMUP_ITERATIONS">
Number of iterations to run for warmup.
</ParamField>

<ParamField path="min_depth" type="int" default="0">
Minimum depth of the modules to inspect, if root level modules is not working, try to increase this value
</ParamField>

<ParamField path="max_depth" type="int" default="5">
Maximum depth of the modules to inspect
</ParamField>
