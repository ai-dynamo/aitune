```python
aitune.utils.logging.setup_logging(

    capture_warnings: bool = True
)
```

</CodeBlock>

<Indent>

Configure logging for the AITune package.

This function sets up the root logger with appropriate handlers and formatting.
Call this at the start of your application to ensure all logs are displayed.

Example usage:
from aitune import setup_logging, set_module_level
import logging

# Configure with a log file and custom format
setup_logging(
    level=logging.DEBUG,
    format_string="%(asctime)s - %(name)s - %(filename)s:%(lineno)d - %(levelname)s - %(message)s",
    log_file="aitune.log",
)

# Set specific modules to different levels
set_module_level("aitune.torch.backend.tensorrt", logging.DEBUG)  # Verbose TensorRT logs

**Parameters:**

<ParamField path="level" type="int | str | None" default="None">
Logging level (default: None, uses current root logger level)
</ParamField>

<ParamField path="format_string" type="str" default="'%(asctime)s - %(name)s - %(filename)s:%(lineno)d - %(levelname)s - %(message)s'">
Format for log messages
</ParamField>

<ParamField path="log_file" type="str | Path | None" default="None">
Optional file path to write logs to
</ParamField>

<ParamField path="capture_warnings" type="bool" default="True">
If True, warnings will be captured and displayed
</ParamField>


</Indent>
