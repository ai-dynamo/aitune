Return the execution device of the tuned submodule owning the first parameter or buffer of a module.

**Parameters:**

<ParamField path="module" type="nn.Module">
Module whose first parameter or buffer determines its reported device.
</ParamField>

**Returns:** `torch.device | None`

The device of the nearest AOT- or JIT-tuned module containing that tensor, or None if there is none.

**Examples:**

<Indent>

Make the `device` property of a library base class report the execution device of tuned submodules.

Diffusers and Transformers report the device of a module's first parameter or buffer. After tuning,
parameters of tuned submodules are offloaded to meta, so their parents would report the meta device.

**Parameters:**

<ParamField path="cls" type="type">
Class defining a `device` property. Classes without one are left unchanged.
</ParamField>


</Indent>
