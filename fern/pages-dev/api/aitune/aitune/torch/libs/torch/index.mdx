Prepare and export a module through ``torch.export.export``.

**Parameters:**

<ParamField path="use_auto" type="bool" default="True">
Use automatic constraints for non-batch dynamic dimensions. Set to
``False`` when a consumer requires explicit minimum and maximum bounds.
</ParamField>

<ParamField path="strict" type="bool" default="True">
Whether Torch Export should use strict tracing.
</ParamField>

<ParamField path="fallback_to_dynamic_hints" type="bool" default="False">
Retry constraint violations with bounded
``Dim.DYNAMIC`` hints instead of explicit dimensions.
</ParamField>
