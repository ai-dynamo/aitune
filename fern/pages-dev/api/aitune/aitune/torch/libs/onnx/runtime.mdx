Shared ONNX Runtime execution with Torch inputs.

## Module Contents

### Functions

| Name | Description |
|------|-------------|
| [`_bind_inputs`](#aitune-torch-libs-onnx-runtime-_bind_inputs) | Bind contiguous CPU or CUDA tensors directly by their memory pointers. |
| [`_bind_outputs`](#aitune-torch-libs-onnx-runtime-_bind_outputs) | Tell ORT to allocate all outputs on the requested device. |
| [`_collect_outputs`](#aitune-torch-libs-onnx-runtime-_collect_outputs) | Collect CPU outputs as arrays or copy CUDA outputs directly to Torch. |
| [`prepare_onnx_inputs`](#aitune-torch-libs-onnx-runtime-prepare_onnx_inputs) | Match positional and named inputs to the original ONNX graph names. |
| [`run_onnx`](#aitune-torch-libs-onnx-runtime-run_onnx) | Bind tensors directly and return outputs on the requested device. |
