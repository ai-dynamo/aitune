**Returns:** [`ProfilingStatus`](#aitune-torch-task-profiling-profiling-ProfilingStatus)

Status of the profiling.

<Note>

The first recorded sample is loaded and expanded to each requested batch
size before `ModelExecutionTimeMeasuringStrategy` starts its timer.
This keeps ``SampleStore`` disk I/O and batch construction out of reported
inference latency and throughput.

</Note>
