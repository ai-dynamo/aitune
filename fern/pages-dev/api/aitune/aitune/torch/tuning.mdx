<Indent>

Save the tuned module to a file.

If storage is not provided, a default storage will be used.

If you would like to save the module to a different folder, you can use the storage parameter.
For example, if you want to save the module to the `ckpt` folder, you can do the following:

**Example**

&gt;&gt;&gt; import doctest
&gt;&gt;&gt; doctest.ELLIPSIS_MARKER = "***" # using *** instead of ... to avoid doctest failure
&gt;&gt;&gt; import aitune.torch as ait
&gt;&gt;&gt; from torch.nn import Linear
&gt;&gt;&gt; strategy = ait.FirstWinsStrategy([ait.backend.TorchEagerBackend()])
&gt;&gt;&gt; _ = strategy.enable_performance_validation(False)
&gt;&gt;&gt; model = ait.Module(Linear(10, 10), "model", strategy=strategy)
&gt;&gt;&gt; dataset = torch.randn(10, 10)
&gt;&gt;&gt; ait.tune(model, dataset, batch_sizes=[1, 2], device="cpu") # doctest: +ELLIPSIS
***🎯 Tuning module: `model` (all graphs)***
&gt;&gt;&gt; storage = ait.LocalTorchStorage(base_folder="ckpt")
&gt;&gt;&gt; ait.save(model, "tuned_model.ait", storage=storage)
***✅ Checkpoint compressed and saved to***
&gt;&gt;&gt; loaded_model = ait.load(model, "tuned_model.ait", storage=storage)
***

**Parameters:**

<ParamField path="module" type="torch.nn.Module">
The module to save.
</ParamField>

<ParamField path="path" type="str | Path">
The path to save the module to.
</ParamField>

<ParamField path="storage" type="Storage | None" default="None">
[`Storage`](./checkpoint/storage.mdx#aitune-torch-checkpoint-storage-Storage) `| None` — The storage to use to save the module. If not provided, a local storage will be used.
</ParamField>


</Indent>

<Indent>

Tune a callable which runs inference on a pipeline or a model.

**Parameters:**

<ParamField path="func" type="Callable">
The function to tune.
</ParamField>

<ParamField path="dataset" type="DatasetLike | DataLoaderFactory | torch.Tensor">
[`DatasetLike`](./dataloader.mdx#aitune-torch-dataloader-DatasetLike) `|` [`DataLoaderFactory`](./dataloader.mdx#aitune-torch-dataloader-DataLoaderFactory) `| torch.Tensor` — The dataset to tune on. It can be DataLoaderFactory or any dataset/iterable and even torch.Tensor.
Tensor will be treated as a single sample dataset.
</ParamField>

<ParamField path="batch_sizes" type="list[int] | None" default="None">
The batch sizes to use for tuning. At least 2 different batch sizes are required for determining
batch axis.
</ParamField>

<ParamField path="max_num_batches_per_batch_size" type="int | None" default="None">
The maximum number of batches to use for tuning per batch size. ``None``
uses all batches; zero yields no batches.
</ParamField>

<ParamField path="device" type="str | torch.device | None" default="None">
The device to use for tuning.
</ParamField>

<ParamField path="dry_run" type="bool" default="False">
If True, only dry run the tuning.
</ParamField>

<ParamField path="disable_external_logging" type="bool" default="False">
If True, libraries logging will be suppressed.
</ParamField>

<ParamField path="clear_cache" type="bool" default="False">
If True, the cache will be cleared before tuning.
</ParamField>

<ParamField path="ignore_failing_modules" type="bool" default="True">
If True, failing modules will be ignored and tuning will continue.
</ParamField>

<Note>

Max batch size is limited by specified batch_size.
Registered modules must be untuned. A loaded checkpoint is deployed and cannot be temporarily deactivated
to free VRAM during tuning.

</Note>


</Indent>
