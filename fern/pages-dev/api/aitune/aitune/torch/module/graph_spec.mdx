GraphSpec used to describe a computational graph.

Each torch module has its own specification of input and output variables. The input specification i.e. args and kwargs
of the torch modules `forward` function is represented by SampleMetadata. Those inputs can change computational
graph. AITune treats each unique input specification as a separate graph which is tuned separately. This object
represents such a computational graph with a name and input_spec information.

Input/output metadata describes tensor paths and shapes. The forward effects specification adds observable
Python behavior: input changes and outputs that reuse input objects. Export and inference share
the user tensor output order, followed by extra tensors needed only to restore changed inputs.

<Indent>

Delegate input mutation restoration and output reconstruction to the forward effects specification.

The specification applies recorded input changes first, then rebuilds the user output so returned
aliases refer to the updated caller-owned objects.

flat_outputs must follow output_names(), including internal state results. arguments contains
the current call's normalized live inputs, not the recorded sample. Optional mutation policies
select copy-back or buffer replacement; see ForwardEffectsSpec.restore_outputs for ownership rules.


</Indent>
