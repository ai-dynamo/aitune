Wrap provided modules with inspection logic.

**Parameters:**

<ParamField path="obj" type="T">
[`T`](#aitune-torch-inspecting-wrapping-T) — Callable object to wrap.
</ParamField>

<ParamField path="modules" type="list[ModuleInfo]">
`list[` [`ModuleInfo`](./module_info.mdx#aitune-torch-inspecting-module_info-ModuleInfo) `]` — Modules to wrap, usually chosen from ``ait.inspect(...).get_modules()``. If that inspection
recorded a call tree (``call_tree=True``), weights of a wrapped module that code outside it reads,
checks the device of, or moves stay on the device when tuning offloads the module (see
``aitune.torch.call_tree.shared_weights_of``), and each kept weight is logged. Wrapping a module again
replaces the weights it keeps; a weight stays kept while any wrapped module keeps it. A ``ModuleInfo``
without ``inspection``, such as one built by hand, keeps nothing.
</ParamField>

<ParamField path="strategy" type="StrategyOption | None" default="None">
[`StrategyOption`](../tune_strategy/resolver.mdx#aitune-torch-tune_strategy-resolver-StrategyOption) `| None` — Strategy to use for patching.
</ParamField>

<ParamField path="strategies" type="StrategyList | StrategyMap | None" default="None">
[`StrategyList`](../module/wrapper_module.mdx#aitune-torch-module-wrapper_module-StrategyList) `|` [`StrategyMap`](../module/wrapper_module.mdx#aitune-torch-module-wrapper_module-StrategyMap) `| None` — Strategies to use for patching.
</ParamField>

**Returns:** [`T`](#aitune-torch-inspecting-wrapping-T) `|` [`Module`](../module/wrapper_module.mdx#aitune-torch-module-wrapper_module-Module)

A `Module` proxy if the root module is selected, otherwise `obj` with its submodules wrapped in place.
