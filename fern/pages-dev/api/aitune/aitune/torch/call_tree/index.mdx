<Indent>

Build the replacement for ``nn.Module._apply`` that ``__enter__`` installs.

``nn.Module._apply`` is the method that ``.to()``, ``.cuda()``, ``.half()`` and similar calls use to convert a
module's parameters and buffers. The replacement runs ``original_apply`` unchanged. While the recorder is
recording, it first records a ``"move"`` access on every tracked weight of the module and, unless
``recurse=False``, of all its submodules: the innermost recorded call's key, or the code found by
``unrecorded_caller`` if no recorded call is running. Only the outermost ``_apply`` of a conversion records,
because ``_apply`` calls itself on each child. Recording goes through the storage map before
``original_apply`` runs, so a tied alias outside the moved subtree is moved as well, and the storage reads
themselves do not count as accesses.

**Parameters:**

<ParamField path="original_apply" type="Callable">
The ``nn.Module._apply`` to call; restored by ``__exit__``.
</ParamField>

**Returns:** `Callable`

A function with the signature of ``nn.Module._apply``.


</Indent>

<Indent>

The weights ``unit`` holds that something outside it still uses or moves.

This is what tuning ``unit`` alone and offloading its weights would break: code outside it that reads one of its
weights (a tied head, ``F.linear(x, unit.weight)`` in a caller's forward), code that looks up a weight's device,
or code outside it that moves its modules with ``.to()`` or ``.cuda()``. Reads and device lookups come from the
ops recorded by ``WeightAccessMode`` during the call-tree pass; moves are recorded by the recorder's
``nn.Module._apply`` probe.

**Parameters:**

<ParamField path="tree" type="CallTree">
[`CallTree`](./call_tree.mdx#aitune-torch-call_tree-call_tree-CallTree) — The call tree from ``ait.inspect(..., call_tree=True)``.
</ParamField>

<ParamField path="unit" type="UnitSpec">
[`UnitSpec`](./units.mdx#aitune-torch-call_tree-units-UnitSpec) — A node path (``"forward &gt; dit_forward"``, see ``CallNode.path``), a module (all its recorded
``forward`` calls), or a list of them as one unit.
</ParamField>

**Returns:** `list[` [`SharedWeight`](#aitune-torch-call_tree-weights-sharing-SharedWeight) `]`

One entry per weight, sorted by name; empty if the unit can be tuned and offloaded on its own.

**Raises:**

- `ValueError`: If ``unit`` is empty, names a path with no recorded call, or is a module that is not part of
the recorded model.
- `TypeError`: If ``unit`` is neither a node path nor a module, nor a list of them.


</Indent>
