Base class for custom AITune Dynamo workers.

Override `setup` and `serve`, then call `run`. An initialized
multi-rank process group starts one endpoint on rank zero while every rank
executes each request.

Example:
    &gt;&gt;&gt; import aitune.dynamo as dyn
    &gt;&gt;&gt; class MyWorker(dyn.DynamoWorker):
    ...     def setup(self):
    ...         pass
    ...     async def serve(self, request):
    ...         yield request
    &gt;&gt;&gt; # MyWorker().run()  # blocks until SIGTERM/SIGINT

Configure how an application-provided callable is exposed through Dynamo.

The application creates and loads the callable passed to `dynamo_worker`.
This configuration only describes its Dynamo endpoint and registration.

**Parameters:**

<ParamField path="type" type="Modality">
[`Modality`](./protocol.mdx#aitune-dynamo-protocol-Modality) — Modality type. One of ``"image"``, ``"video"``, ``"audio"``, ``"embedding"``.
</ParamField>

<ParamField path="model_path" type="str">
Registration reference passed unchanged to Dynamo's
``register_model``. It is not used to create or load the callable.
</ParamField>

<ParamField path="mapping" type="Callable | None" default="None">
Optional adapter ``fn(DynamoRequest) -&gt; dict``. The result is
unpacked as keyword arguments when calling the model. Without a mapping,

<Indent>

Serve a tuned model through a local or collective Dynamo worker.

**Example**

&gt;&gt;&gt; import aitune.dynamo as dyn
&gt;&gt;&gt; import numpy as np
&gt;&gt;&gt; def embed(request):
...     return np.zeros((1, 768))
&gt;&gt;&gt; config = dyn.DynamoWorkerConfig(type="embedding", model_path="org/model")
&gt;&gt;&gt; # dyn.dynamo_worker(embed, config)  # blocks until shutdown

**Parameters:**

<ParamField path="model_or_fn" type="nn.Module | Callable">
A callable, or a ``torch.nn.Module`` with ``config.mapping``.
</ParamField>

<ParamField path="config" type="DynamoWorkerConfig">
[`DynamoWorkerConfig`](#aitune-dynamo-worker-DynamoWorkerConfig) — Modality, endpoint, request mapping, and execution configuration.
</ParamField>

<ParamField path="setup" type="Callable[[], None] | None" default="None">
Optional rank-local model initialization. In collective execution,
every rank must finish this callback before warmup begins.
</ParamField>

<ParamField path="warmup" type="Callable[[], None] | None" default="None">
Optional model warmup run after setup succeeds on every rank.
</ParamField>

**Raises:**

- `ValueError`: If the modality is unsupported or a module has no mapping.
- `ImportError`: If the optional Dynamo dependencies are unavailable.


</Indent>
