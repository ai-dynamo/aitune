<Indent>

Publish a tuned artifact or an existing model file to a Triton repository.

The operation never replaces an existing model. Files are written directly
into the new model directory, so a failure can leave an incomplete directory.
For artifacts, a Model Analyzer config is generated under
``model_analyzer/config.yaml`` with input shapes derived from the artifact.
Without an explicit config, the Triton batch limit and scheduler are derived
from the artifact's tensor bounds and runtime call structure.
Existing model files require an explicit backend-specific ``config`` and
are copied without compilation or tuning. Callers must keep generation
separate from updates to a live Triton repository.

Supported model format/runtime pairs are ``onnx``/``onnxruntime``,
``tensorrt_plan``/``tensorrt``, and ``pt2``/``aotinductor``. ONNX provider
selection comes from ``runtime.options["execution_provider"]``. TensorRT uses
``model.metadata["optimization_profile_count"]`` and the optional runtime
setting ``use_cuda_graphs``. PT2 uses ``model.metadata["structured_call"]``.

**Parameters:**

<ParamField path="model" type="DeploymentArtifact | str | os.PathLike[str]">
[`DeploymentArtifact`](../records/artifact.mdx#aitune-records-artifact-DeploymentArtifact) `| str | os.PathLike[str]` — Deployment artifact or path to an existing model file.
</ParamField>

<ParamField path="path" type="str | os.PathLike[str]">
Triton model repository root.
</ParamField>

<ParamField path="model_name" type="str | None" default="None">
New model directory name for an artifact; defaults to ``config.name`` when config is supplied.
</ParamField>

<ParamField path="model_version" type="int" default="1">
Positive Triton model version.
</ParamField>

<ParamField path="model_analyzer" type="ModelAnalyzerConfig | None" default="None">
[`ModelAnalyzerConfig`](./model_analyzer.mdx#aitune-triton-model_analyzer-ModelAnalyzerConfig) `| None` — Optional Model Analyzer options. Omission uses the default options for artifacts.
</ParamField>

<ParamField path="config" type="TensorRTModelConfig | ONNXRuntimeModelConfig | TorchAOTIModelConfig | None" default="None">
[`TensorRTModelConfig`](./config/tensorrt.mdx#aitune-triton-config-tensorrt-TensorRTModelConfig) `|` [`ONNXRuntimeModelConfig`](./config/onnx_runtime.mdx#aitune-triton-config-onnx_runtime-ONNXRuntimeModelConfig) `|` [`TorchAOTIModelConfig`](./config/torch_aoti.mdx#aitune-triton-config-torch_aoti-TorchAOTIModelConfig) `| None` — Complete backend-specific configuration. For an artifact, it is derived when omitted. A supplied
config must match the artifact runtime and model name; the caller owns its other values. An existing
model file requires it.
</ParamField>

<ParamField path="additional_files" type="Sequence[str | os.PathLike[str]]" default="()">
ONNX external-data paths relative to the source file's directory.
</ParamField>

<ParamField path="resources" type="Mapping[str, str | os.PathLike[str]] | None" default="None">
Model-relative auxiliary destination paths mapped to local files.
</ParamField>

**Returns:** `Path`

Path to the generated model directory.

**Raises:**

- `AITuneUserInputError`: If publication arguments are invalid.
- `AITunePublicationError`: If the artifact cannot be represented or publication fails.


</Indent>
