Collective request execution for Dynamo workers.

## Module Contents

### Functions

| Name | Description |
|------|-------------|
| [`_broadcast_collective_command`](#aitune-dynamo-distributed-_broadcast_collective_command) | Broadcast a request-control command from rank zero. |
| [`_collective_errors`](#aitune-dynamo-distributed-_collective_errors) | Collect an error description from every worker rank. |
| [`_collective_leader_serve`](#aitune-dynamo-distributed-_collective_leader_serve) | Serialize rank-zero requests and execute each request on every rank. |
| [`_execute_collective_request`](#aitune-dynamo-distributed-_execute_collective_request) | Execute one request locally and report rank-local failures collectively. |
| [`_receive_collective_command`](#aitune-dynamo-distributed-_receive_collective_command) | Receive and validate one request-control command on a follower rank. |
| [`_receive_collective_requests`](#aitune-dynamo-distributed-_receive_collective_requests) | Execute rank-zero commands on a follower using one persistent event loop. |
| [`_run_collective_follower`](#aitune-dynamo-distributed-_run_collective_follower) | Receive rank-zero commands and execute requests without starting an endpoint. |
| [`_run_collective_setup`](#aitune-dynamo-distributed-_run_collective_setup) | Run a startup stage on every rank and prevent a partial worker from serving. |
| [`is_rank_zero`](#aitune-dynamo-distributed-is_rank_zero) | Return whether the current process owns the Dynamo endpoint and responses. |
| [`run_collective_dynamo_worker`](#aitune-dynamo-distributed-run_collective_dynamo_worker) | Serve one endpoint from rank zero while every rank executes each request. |
| [`should_run_collectively`](#aitune-dynamo-distributed-should_run_collectively) | Return whether the application-owned process group requires collective serving. |
